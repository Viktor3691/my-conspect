Математические операции с числами в JavaScript

Сложение:

script.js 
let a = 1 + 2;
alert(a); // выведет 3

Вычитание:

script.js 
let b = 3 - 2;
alert(b); // выведет 1

Умножение:

script.js 
let c = 3 * 2;
alert(c); // выведет 6

Деление:

script.js 
let d = 4 / 2;
alert(d); // выведет 2

Задача 1

Создайте переменную a. Запишите в нее сумму чисел 1, 2 и 3. С помощью функции alert выведите на экран содержимое переменной a.

script.js 
let a = 1 + 2 + 3;
alert(a); // выведет 6

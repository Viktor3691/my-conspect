Дроби в JavaScript

В JavaScript можно работать с десятичными дробями. При этом целая и дробная части отделяются друг от друга точкой.
Смотрите пример:

script.js 
let a = 0.5;
alert(a); // выведет 0.5

Смотрите еще пример:

script.js 
let a = 0.5 + 0.5;
alert(a); // выведет 1

Задача 1

Запишите в переменную a число 1.5, а в переменную b - число 0.75. Найдите сумму значений этих переменных и выведите ее на экран.

script.js 
let a = 1.5;
let b = 0.75;
alert(a + b); // выведет 2.25;

Поиск ошибок в коде

В следующих задачах некоторый программист написал код и, возможно, допустил в нем ошибки. Вы должны проверить, делает ли код то, что описано. Если код работает некорректно, вы должны исправить ошибки.

Задача 1

Код должен находить сумму чисел:

script.js 
let num11 = 1;
let num12 = 2;
console.log('сумма: ' + num11 + num12); // сумма: 12

Решение

script.js 
let num11 = 1;
let num12 = 2;
console.log(`сумма: `, num11 + num12); // сумма: 3

Задача 2

Код должен находить сумму чисел:

script.js 
let a = 1;
let b = 2;
console.log(a + b + c);
// Uncaught ReferenceError: c is not defined. Переменная не объявлена.

Решение

script.js 
let a = 1;
let b = 2;
let c = 3;
console.log(a + b + c); // 6

Задача 3

Код должен находить сумму цифр числа:

script.js 
let num31 = '123';
let sum3 = num31[0] + num31[1] + num31[2];
console.log(sum3); // 123

Решение

script.js 
let num31 = '123';
let sum3 = +num31[0] + +num31[1] + +num31[2];
console.log(sum3); // 6

Задача 4

Код должен вывести первую цифру числа:

script.js 
let num41 = 123;
console.log(num41[0]); // undefined

Решение

script.js 
let num41 = 123;
num41 = String(123);
console.log(num41[0]); // 1
Задача 5

Код должен был вывести в консоль число 1, но выводит 0:

script.js 
let a5 = 0;
console.log(a5++); // 0

Решение

script.js 
let a5 = 0;
console.log(++a5); // 1

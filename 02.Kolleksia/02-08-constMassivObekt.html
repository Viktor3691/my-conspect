Константы с массивами или объектами в JavaScript

Константы, содержащие массивы и объекты, работают интересным образом. JavaScript не разрешает изменять значения этих констант, но изменять свойства объектов и значения элементов массивов - можно.
Давайте посмотрим на примерах. Пусть у нас дан вот такой объект:

script.js 
const obj = {a: 1, b: 2, c: 3};
// Давайте попробуем записать в него что-то другое:
obj = 123; // ошибка
// Давайте попробуем записать в константу другой объект:
obj = {x: 1, y: 2, z: 3}; // ошибка
// Однако, если мы попробуем изменить свойство объекта, то это сработает:
obj.a = '+'; // работает!

Пример

script.js 
const obj = { a: 1, b: 2, c: 3 };
// ✅ Можно менять свойства существующего объекта
obj.a = 10; // теперь obj.a === 10
obj.b = 'новое'; // obj.b теперь строка
obj.c = true; // obj.c теперь boolean
// ✅ Можно добавлять новые свойства
obj.d = 'добавлено'; // у obj теперь есть свойство d
// ✅ Можно удалять свойства
delete obj.c; // свойства c больше нет
console.log(obj);
// Вывод: { a: 10, b: 'новое', d: 'добавлено' }
// ❌ Нельзя переприсвоить константе другой объект
obj = { x: 1 }; // TypeError: Assignment to constant variable
// ❌ Нельзя сделать obj примитивом
obj = 123; // тоже ошибка

Задача 1

Что выведется в результате выполнения следующего кода:

script.js 
const arr = ['a', 'b', 'c'];
arr[1] = '!';
console.log(arr); // (3) ['a', '!', 'c']

Задача 2

Что выведется в результате выполнения следующего кода:

script.js 
const arr = ['a', 'b', 'c'];
arr = [1, 2, 3];
console.log(arr);
 // Uncaught TypeError: Assignment to constant variable.

Задача 3

Что выведется в результате выполнения следующего кода:

script.js 
const arr = ['a', 'b', 'c'];
arr = ['a', 'b', 'c'];
console.log(arr);
// Uncaught TypeError: Assignment to constant variable.

Ошибка Uncaught TypeError: Assignment to constant variable появляется, когда ты пытаешься переприсвоить переменной, объявленной через const, новое значение.

Поиск ошибок в коде с массивами и объектами JavaScript

В следующих задачах некоторый программист написал код и, возможно, допустил в нем ошибки. Вы должны проверить, делает ли код то, что описано. Если код работает некорректно, вы должны исправить ошибки.

Задача 1

Код должен вывести последний элемент массива:

script.js 
let arr = [1, 2, 3, 4, 5];
console.log(arr[arr.length]); // undefined

Решение

script.js 
let arr = [1, 2, 3, 4, 5];
console.log(arr[arr.length - 1]); // 5

Задача 2

Код должен найти сумму элементов массива:

script.js 
let arr = [1, 2, 3, 4, 5];
console.log(arr[1] + arr[2] + arr[3] + arr[4] + arr[5]); // NaN

Решение

script.js 
let arr = [1, 2, 3, 4, 5];
console.log(arr2[0] + arr2[1] + arr2[2] + arr2[3] + arr2[4]); // 15

Задача 3

Код должен вывести длину массива:

script.js 
let arr = {1, 2, 3, 4, 5};
console.log(arr.length]);

Решение

script.js 
let arr = [1, 2, 3, 4, 5]; // {} - []
console.log(arr.length); // ]

Задача 4

Код должен вывести элемент объекта:

script.js 
let obj = {a: 1, b: 2, c: 3};
console.log(obj[a]); // Uncaught ReferenceError: a is not defined

Решение

script.js 
let obj = {a: 1, b: 2, c: 3};
console.log(obj['a']); // 1  [a] - ['a']

Задача 5

:

Код должен вывести элемент объекта по ключу из переменной

script.js 
let obj = {a: 1, b: 2, c: 3};
let key = 'a';

console.log(obj.key); // undefined

Решение

obj.key — это обращение к свойству с буквальным именем key, нужно получить значение по ключу, который хранится в переменной key. Для этого используют квадратные скобки:

script.js 
let obj = {a: 1, b: 2, c: 3};
let key = 'a';

console.log(obj5[key]); // 1 console.log(obj.key) - console.log(obj5[key])

Задача 6

Код должен вывести сумму элементов объекта:

script.js 
let obj = {a: 1, b: 2, c: 3};
let sum = obj[a] + obj[b] + obj[c];

console.log(obj); // Uncaught ReferenceError: a is not defined

Решение

script.js 
let obj6 = { a: 1, b: 2, c: 3 };
let sum6 = obj6['a'] + obj6['b'] + obj6['c']; // obj[a] - obj6['a']

console.log(sum6); // 6 console.log(obj6); - console.log(sum6);

Задача 7

Код должен вывести количество элементов объекта:

script.js 
let obj = {a: 1, b: 2, c: 3};
console.log(obj.length); // undefined

Решение

В этом коде ошибка: у обычных объектов ({}) в JavaScript нет свойства length — оно есть только у массивов.
Для учебных задач чаще всего достаточно самого простого варианта: Object.keys(obj).length

script.js 
let obj = {a: 1, b: 2, c: 3};
console.log(Object.keys(obj).length); // ✅ Выведет: 3

Альтернативные способы

Через for...in с проверкой собственных свойств:

script.js 
let obj = {a: 1, b: 2, c: 3};
let count = 0;
for (let key in obj) {
if (obj.hasOwnProperty(key)) {
count++;
}
}
console.log(count); // 3

Через Object.values():

script.js 
let obj = {a: 1, b: 2, c: 3};
console.log(Object.values(obj).length); // 3

Как это работает

Object.values(obj) возвращает массив значений объекта: [1, 2, 3]. У этого массива есть свойство .length, которое и даёт количество элементов — 3.

Через Object.entries():

script.js 
let obj = {a: 1, b: 2, c: 3};
console.log(Object.entries(obj).length); // 3

Как это работает

Object.entries(obj) возвращает массив пар [ключ, значение]:
[ ['a', 1], ['b', 2], ['c', 3] ].
У этого массива есть свойство .length — оно и даёт количество пар, то есть количество свойств объекта: 3.

Чем это отличается от других способов

Object.keys(obj).length — считает только ключи.
Object.values(obj).length — считает только значения.
Object.entries(obj).length — считает пары ключ‑значение. Для простого подсчёта количества свойств все три варианта дадут одинаковый результат.
Зато Object.entries() особенно полезен, если нужно сразу работать и с ключами, и со значениями — например, в цикле:

script.js 
for (const [key, value] of Object.entries(obj)) {
console.log(`${key}: ${value}`);
}
// Выведет:
// a: 1
// b: 2
// c: 3

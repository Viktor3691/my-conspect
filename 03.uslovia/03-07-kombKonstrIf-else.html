Комбинации конструкций if-else в JavaScript

Пусть переменная num может принимать значения 1, 2 или 3.
Пусть также для каждого значения мы хотим выводить на экран свою строку, например, если num имеет значение 1, то выведем строку 'value1', если значение 2, то 'value2' и так далее.
Для решения задачи можно просто написать три if без else:

script.js 
let num = 1; // может быть 1, 2 или 3

if (num == 1) {
alert('value1'); // сработает, если num равно 1
}

if (num == 2) {
alert('value2'); // сработает, если num равно 2
}

if (num == 3) {
alert('value3'); // сработает, если num равно 3
}

Задача 1

В переменной day лежит какое-то число из интервала от 1 до 31. Определите в какую декаду месяца попадает это число (в первую, вторую или третью).

script.js 
let day1 = 15;

if (day1 > 0 && day1 <= 10) {
alert(`1 декада`)
};

if (day1 > 10 && day1 <= 20) {
alert(`2 декада`)
};

if (day1 > 20 && day1 <= 31) {
alert(`3 декада`)
};
2 декада

Конструкция else if

Приведенный выше код можно переписать через специальную конструкцию else if:

script.js 
 let num = 1;
 
 if (num == 1) {
 alert('value1');
 } else if (num == 2) {
 alert('value2');
 } else if (num == 3) {
 alert('value3');
 }

Важный нюанс: == vs ===

В учебных примерах часто пишут ==, но в реальном коде почти всегда используют === (строгое равенство). Разница:
== делает неявное приведение типов.
=== сравнивает и значение, и тип. Пример, где это важно:

script.js 
let num = '1';

if (num == 1) { // true: строка '1' приводится к числу 1
alert('совпало по ==');
}

if (num === 1) { // false: тип разный (string vs number)
alert('не совпало по ===');
}

когда будешь писать свой код — лучше сразу привыкать к ===.

Добавим else для полноты картины

Часто полезно добавить ветку «ничего не подошло»:

script.js 
let num = 5;

if (num === 1) {
alert('value1');
} else if (num === 2) {
alert('value2');
 } else if (num === 3) {
alert('value3');
} else {
alert('значение не подходит ни под одно условие');
 }
значение не подходит ни под одно условие

Задача 2

Решите предыдущую задачу на декады месяца через конструкцию else if.

Решение через else if

script.js 
 let day2 = 25;

if (day2 >= 1 && day2 <= 10) {
alert('1 декада');
 } else if (day2> 10 && day2 <= 20) {
alert('2 декада');
} else if (day2> 20 && day2 <= 31) {
alert('3 декада');
} else {
 alert('Некорректное значение дня');
}
3 декада

Почему так лучше

  • Как только сработает одно условие — остальные else if не проверяются. Это и быстрее, и понятнее по логике «или‑или».
  • Блок else ловит все случаи вне диапазона 1–31 — это защита от ошибок (например, если случайно будет day2 = 0 или day2 = 40).

Про === vs сравнение диапазонов

В твоём примере с num === 1 ты сравниваешь на точное равенство. А здесь у нас диапазоны, поэтому === не подходит: нужно именно сравнение >, <,>=, <=. И тут как раз уместно использовать===для проверки типа, если боишься, что в переменную попадёт строка:

Как это связать с предыдущими темами

  • Приоритет операций: в условии day2 >= 1 && day2 <= 10 сначала выполняются сравнения (>=, <=), а потом логическое И (&&). Это как раз тот приоритет, который ты разбирал.
  • Сокращённые сравнения: тут их не применить, потому что у нас не проверка на истинность переменной, а проверка диапазона. Сокращённые формы полезны, когда пишешь if (test) вместо if (test===true).

Преимущество else if

Преимуществом использования else if вместо нескольких ифов является возможность отловить ситуацию, когда значение переменной num не подходит ни под одно из условий:

script.js 
let num = 1;

if (num == 1) {
alert('value1');
} else if (num == 2) {
alert('value2');
} else if (num == 3) {
alert('value3');
} else {
alert('неверное значение переменной num');
}

Вложенные if

Конструкции if-else можно вкладывать друг в друга произвольным образом. Смотрите пример:

script.js 
let num = 3;

if (num >= 0) {
  if (num <= 5) {
    alert('меньше или равно 5');
  } else {
    alert('больше 5'); }
  } else {
    alert('меньше нуля');
}

Задача4

Пусть в переменной num хранится число. Если это число не попадает в диапазон от 10 до 99, то выведите на экран сообщение об этом. Если же число попадает в указанный диапазон, то найдите сумму цифр этого числа. Если полученная сумма меньше или равна 9, то выведите на экран сообщение о том, что сумма цифр однозначна, в противном случае выведите сообщение о том, что сумма цифр двузначна.

script.js 
мой вариант
let num4 = 55;
let str4 = String(num4);

if (num4 > 99) {
alert('число не попадает в диапазон от 10 до 99')
} else if ((+str4[0] + +str4[1]) <= 9) {
alert('сумма меньше или равна 9')
} else {
alert((+str4[0] + +str4[1]))
}
10

код почти работает, но в нём есть логическая ошибка: он не проверяет нижнюю границу диапазона (числа меньше 10) и неправильно обрабатывает случаи вне диапазона.

Что не так

  • Условие if (num4 > 99) ловит только числа больше 99, а числа меньше 10 (например, 5 или 0) сразу попадают в else if и обрабатываются как будто они в диапазоне.
  • В else выводится сама сумма, а по условию нужно вывести сообщение о том, что сумма двузначна.

Исправленный вариант

script.js 
let num4 = 55;

if (num4 < 10 || num4> 99) {
   alert('Число не попадает в диапазон от 10 до 99');
} else {
   const str4 = String(num4);
   const sum = +str4[0] + +str4[1];

   if (sum <= 9) {
       alert('Сумма цифр однозначна');
   } else {
       alert('Сумма цифр двузначна');
   }
}

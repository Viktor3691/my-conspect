Тернарный оператор в JavaScript

Тернарный оператор в JavaScript — это компактный способ записать условие, аналог простой конструкции if‑else. Он возвращает значение, поэтому его удобно использовать для присваивания или в выражениях.

Синтаксис

script.js 
условие ? выражениеЕслиИстина : выражениеЕслиЛожь
  • Если условие истинно (truthy), выполнится и вернётся выражениеЕслиИстина.
  • Если ложно (falsy) — вернётся выражениеЕслиЛожь.

Базовые примеры

Присваивание значения по условию:

script.js 
const age = 20;

const status = age >= 18 ? 'совершеннолетний' : 'несовершеннолетний';
console.log(status);
 // "совершеннолетний"

Это то же самое, что:

script.js 
let status;

if (age >= 18) {
status = 'совершеннолетний';

} else {
status = 'несовершеннолетний';
}

Использование прямо в выводе:

script.js 
console.log(идёт дождь ? 'Возьми зонт' : 'Можно без зонта');

В шаблонной строке:

script.js 
const isNew = true;
console.log(`Товар ${isNew ? 'новый' : 'б/у'}`);

Проверка возраста

script.js 
let age = 17;
let adult = age >= 18 ? true : false;
console.log(adult);
// false

Выбор текста по диапазону

Допустим, нужно вывести категорию по числу:

script.js 
const num = 45;
const category = num < 10 ? 'однозначное' : num < 100
? 'двузначное' : 'трёхзначное и более' ;
console.log(category);
// "двузначное"

Здесь используется вложенный тернарный оператор. Он допустим для простых случаев, но если условий много, лучше взять if/else if или switch — так код легче читать и поддерживать.

Важные нюансы для начинающего разработчика

  1. Тернарный оператор — это выражение. Он что‑то возвращает, а if — это инструкция (statement). Поэтому тернарный можно писать там, где ожидается значение (в присваивании, аргументах функций, шаблонных строках).
  2. Не стоит делать сложные ветки. Если внутри ? или : много действий, лучше оставить if/else.
  3. Приоритет и скобки. В сложных выражениях лучше ставить скобки, чтобы явно показать порядок:
    script.js 
    const result = (a > b ? a : b) + 1;
  4. Truthy/falsy. Условие работает так же, как в if: пустые строки, 0, null, undefined, NaN считаются ложными. Если важна точность (например, отличить 0 от null), лучше писать явные сравнения.

Частые полезные шаблоны

Значение по умолчанию:

script.js 
const name = '';
const displayName = name.trim() !== '' ? name : 'Аноним';

Разбор по шагам:

  1. name.trim() — убирает пробелы по краям строки.
  2. name.trim() !== '' — проверяет: «осталось ли что-то после удаления пробелов?»
  3. Если ДА (строка не пустая) → берём name.
  4. Если НЕТ (строка пустая или состоит из одних пробелов) → берём 'Аноним'.

Результат для name = '':

  • ''.trim() → ''
  • '' !== '' → false
  • Тернарник вернёт 'Аноним'.

Выбор класса/стиля:

script.js 
const isDark = true;
const bgColor = isDark ? 'black' : 'white';
const textColor = isDark ? 'white' : 'black';
console.log(bgColor, textColor);
// 'black', 'white'

Возврат из функции:

script.js 
function getStatus(isOnline) {
return isOnline ? 'online' : 'offline';
}

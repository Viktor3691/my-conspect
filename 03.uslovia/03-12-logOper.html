Логические операции в JavaScript

Операторы сравнения можно использовать вне конструкций if. Смотрите пример:

script.js 
console.log(1 == 1); // выведет true
console.log(1 == 2); // выведет false

Можно сравнивать переменные:

script.js 
let a = 1;
let b = 2;

console.log(a == b);

Можно не выводить результат сразу в консоль, а присвоить его какой-нибудь переменной:

script.js 
let a = 1;
 let b = 2;

let result = a == b;
console.log(result);
// false

Задача №1

Пусть даны следующие переменные:

script.js 
let a = 2 * (3 - 1);
let b = 6 - 2;

Используя оператор ==, узнайте, равны ли значения этих переменных или нет.

Решение 1

script.js 
let a1 = 2 * (3 - 1);
let b1 = 6 - 2;

let res1 = a1 == b1 ? ' значения переменных равны' : 'значения переменных НЕ равны'
console.log(res1);
console.log(a1 == b1);

Задача №2

Пусть даны следующие переменные:

script.js 
let a = 5 * (7 - 4);
let b = 1 + 2 + 7;
.

Используя оператор >, узнайте, больше ли переменная a, чем b

Решение

script.js 
let a2 = 5 * (7 - 4);
let b2 = 1 + 2 + 7;

let res2 = a2 > b2 ? 'переменная a больше b' : 'переменная a меньше b'
console.log(res2);
console.log(a2 > b2);

Задача №3

Пусть даны следующие переменные:

script.js 
let a = 2 ** 4;
let b = 4 ** 2;
.

Используя операцию оператор !=, узнайте, разные ли значения этих переменных или нет

script.js 
let a3 = 2 ** 4;
let b3 = 4 ** 2;

console.log(a3); //16
console.log(b3); //16

let res3 = a3 != b3 ? 'переменные РАЗНЫЕ' : 'переменные НЕ РАЗНЫЕ'
console.log(res3);
console.log(a3 != b3);

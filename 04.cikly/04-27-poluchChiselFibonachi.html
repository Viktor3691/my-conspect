Получение чисел Фибоначчи в JavaScript

Сейчас мы с вами научимся получать числа Фибоначчи.

Данные числа представляют собой последовательность, в которой первые два числа равны 0 и 1, а каждое последующее число равно сумме двух предыдущих чисел. Вот решение описанной задачи:

script.js 
 let one = 0;
 let two = 1;

for (let i = 1; i <= 10; i++) {
let current=one + two;
one=two;
two=current;

console.log(current);
}

Задача 1

Разберите мое решение описанной задачи, а затем самостоятельно, не подсматривая в мой код, решите эту задачу.

script.js 
let one1 = 0;
let two1 = 1;

for (let i = 1; i <= 10; i++) {
let current = one1 + two1;
one1 = two1;
two1 = current;

}

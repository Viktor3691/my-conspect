Заполнение массивов с накоплением строки в JavaScript

Давайте заполним массив следующим образом: в первый элемент запишем 'x', во второй 'xx', в третий 'xxx' и так далее.

Задача аналогична пирамидке, разница в том, что мы не будем выводить формируемую строку на экран, а будем записывать ее в массив, вот так:

script.js 
let arr = [];
let str = '';

for (let i = 0; i < 5; i++) {
str +='x' ;
arr.push(str);
}
 console.log(arr);
// выведет ['x', 'xx' , 'xxx', 'xxxx' , 'xxxxx' ]

Задача 1

С помощью цикла сформируйте следующий массив:

['xx', 'xxxx', 'xxxxxx' , 'xxxxxxxx' , 'xxxxxxxxxx' ]

Решение

script.js 
let arr1 = [];
let str1 = '';

for (let i = 0; i < 5; i++) {
str1 += 'x' + 'x';
arr1.push(str1);
}
document.write('arr1 = [', arr1, '];');

Заполнение массива числами

Давайте теперь заполним массив следующим образом: в первый элемент запишем '1' , во второй '22' , в третий '333' и так далее.

Данная задача также аналогична пирамидке. Реализуем:

script.js 
let arr=[];

for (let i=1; i < 10; i++) {
let str='' ;

for (let j=0; j < i; j++) {
str +=i;
}
arr.push(str);
}

console.log(arr);

Задача 2

С помощью цикла сформируйте следующий массив: ['11111', '22222' , '33333' , '44444' , '55555' ]

Решение

script.js 
let arr2 = [];

for (let i = 1; i <= 5; i++) {
    let str2 = '';

    for (let j = 0; j < i; j++) {
        str2 += i;
    }
    arr2.push(str2);
}
document.write('arr2 = ', JSON.stringify(arr2), ';');

JSON.stringify(arr2) — это метод, который превращает JavaScript‑массив (или объект) в строку в формате JSON.

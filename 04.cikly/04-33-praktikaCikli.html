Отработка циклов JavaScript

Задача 1

Выведите с помощью цикла столбец чисел от 1 до 10.

Решение

script.js 
for (let i = 1; i <= 10; i++) {
console.log(i);
}

Задача 2

Выведите с помощью цикла столбец чисел от 10 до 1.

Решение

script.js 
for (let i = 10; i >= 0; i--) {
     console.log(i);
}

Задача 3

Выведите с помощью цикла столбец четных чисел от 1 до 10.

Решение

script.js 
for (let i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        console.log(i);
    }
}

Задача 6

Дан массив с числами. С помощью цикла выведите только те элементы массива, которые больше нуля и меньше 10-ти.

Решение

script.js 
let arr6 = [-1, -3, 0, 1, 3, 5, -10, 15, 7];

for (let i = 0; i < arr6.length; i++) {
    if (arr6[i] > 0 && arr6[i] < 10) {
        document.write(arr6[i], ', ');
    }
}

Задача 10

Дан массив с числами. Найдите среднее арифметическое его элементов (сумма элементов, делить на количество).

Решение

script.js 
let arr10 = [1, 3, 0, 1, 3, 5, 10, 15, 7];
let sum10 = 0;
let kol10 = 0;

for (let i = 1; i < arr10.length; i++) {
sum10 += arr10[i];
kol10++;
}
document.write('kol = ', kol10, ' ');
document.write('sum10 = ', sum10);
document.write(' среднее арифметическое = ', sum10 / kol10);

Задача 11

Напишите скрипт, который будет находить факториал числа. Факториал (обозначается !) - это произведение (умножение) всех целых чисел, меньше данного, и его самого. Например, 4! = 1*2*3*4.

Решение

script.js 
function factorial(n) {
// Проверка на корректность ввода
    if (n < 0 || !Number.isInteger(n)) {
        return 'Ошибка: введите целое неотрицательное число';
    }

    let result = 1;
    for (let i = 2; i <= n; i++) {
        result *= i; // то же самое, что result = result * i
    }
    return result;
}

if (n < 0 || !Number.isInteger(n))

  • n < 0 — проверяет, что число не отрицательное. Факториал определён только для неотрицательных целых чисел: 0 ! , 1 ! , 2 ! , … 0!,1!,2!,…
  • || — логическое «ИЛИ». Условие сработает, если верно хотя бы одно из двух: либо число отрицательное, либо не целое.
  • !Number.isInteger(n) — это «не целое число».
    • Number.isInteger(n) возвращает true, если n — целое (например, 5, 0, -3).
    • Восклицательный знак ! инвертирует результат: !true → false, !false → true. То есть !Number.isInteger(n) будет true, когда n дробное (например, 3.5, 2.1).

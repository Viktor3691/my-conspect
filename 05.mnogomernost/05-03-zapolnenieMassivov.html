Заполнение многомерных массивов JavaScript

Пусть теперь мы хотим в цикле создать какой-нибудь многомерный массив с числами.

Например, вот такой двухмерный массив:

[[1, 2, 3], [1, 2, 3], [1, 2, 3]]

Решим поставленную задачу, применив два вложенных цикла. Внешний цикл будет создавать подмассивы, а внутренний - заполнять эти подмассивы числами:

let arr = []; for (let i = 0; i < 3; i++) { arr[i]=[]; // создаем подмассив for (let j=0; j < 3; j++) { arr[i][j]=j + 1;// заполняем подмассив числами } } console.log(arr);

Вместо обращения arr[i][j] можно использовать метод push:

let arr=[]; for (let i=0; i < 3; i++) { arr[i]=[]; for (let j=0; j < 3; j++) { arr[i].push(j + 1); } } console.log(arr); Задача 1⋕js.Pm.Md.MAF.1

Потенциальная проблема

Давайте рассмотрим код, полученный нами выше:

let arr=[]; for (let i=0; i < 3; i++) { arr[i]=[]; // обратите внимание на эту строчку for (let j=0; j < 3; j++) { arr[i][j]=j + 1; } } console.log(arr);

В этом коде важное место занимает строчка arr[i]=[].

Эта строчка предназначена для создания подмассива. Мы не можем опустить эту строчку, так как тогда во внутреннем цикле обращение arr[i][j] выдаст ошибку.

Почему: потому что arr[i] не будет являться массивом (а будет undefined), а мы будем обращаться к нему, как к массиву, пытаясь добавить в этот подмассив элемент, вот так: arr[i][j].

Такая же ошибка будет, если вместо arr[i][j] добавлять элемент через arr[i].push(j).

Заполнение числами по порядку В предыдущих примерах все числа в подмассивах были одинаковыми.

Давайте теперь сделаем так, чтобы числа возрастали, вот так:

[[1, 2, 3], [4, 5, 6], [7, 8, 9]]

Для этого нужно сделать специальную переменную-счетчик, которая будет увеличивать свое значение на 1 при каждой итерации внутреннего цикла. Значение этого счетчика мы и будем записывать в массив, вот так:

let arr=[]; let k=1; // счетчик for (let i=0; i < 3; i++) { arr[i]=[]; for (let j=0; j < 3; j++) { arr[i][j]=k; // записываем счетчик k++; // увеличиваем счетчик } } console.log(arr);

Можно уменьшить код, занеся определение счетчика в первый цикл, а k++ - во второй:

let arr=[]; for (let i=0, k=1; i < 3; i++) { arr[i]=[]; for (let j=0; j < 3; j++, k++) { arr[i][j]=k; } } console.log(arr);

Можно также сделать увеличение счетчика после присваивания:

let arr=[]; for (let i=0, k=1; i < 3; i++) { [i]=[]; for (let j=0; j < 3; j++) { arr[i][j]=k++; } } console.log(arr);

Обратите внимание на то, что в данном случае должно быть обязательно k++, а не ++k, так как второй вариант сначала выполнит увеличение счетчика, а уже потом запись в массив

(то есть в результате массив начнется с двойки, а не с единицы, вот так:
[[2, 3, 4], [5, 6, 7], [8, 9, 10]])

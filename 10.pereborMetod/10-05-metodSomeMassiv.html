Метод some для проверки массива в JavaScript

Следующий метод some проверяет элементы массива и возвращает true, если хотя бы для одного элемента коллбэк вернул true, в противном случае метод возвращает false. Проверим, к примеру, что в массиве есть хотя бы одно четное число: let arr = [2, 4, 6, 8]; let result = arr.some(function(elem) { return elem % 2 == 0; }); console.log(result); Упростим: let arr = [2, 4, 6, 8]; let result = arr.some(elem => elem % 2 == 0); console.log(result); Задача 1⋕js.Pm.Enm.Sm.1 Дан массив с числами. Проверьте то, что в массиве есть хотя бы одно число больше нуля. Задача 2⋕js.Pm.Enm.Sm.2 Дан массив с числами. Проверьте то, что хотя бы для одного элемента произведение его значения на порядковый номер больше 30.

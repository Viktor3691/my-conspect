Получения дня недели на JavaScript

С помощью объекта Date можно также получить номер текущего дня недели. Делается это с помощью метода getDay. Этот метод возвращает числа от 0 до 6-ти, причем неделя начинается с воскресенья и этот день имеет номер 0. Понедельник - это день номер 1, вторник - номер 2 и так далее. Давайте посмотрим работу метода getDay на примере. Пусть, к примеру, сегодня вторник. Тогда следующий код выведет число 2: let date = new Date(); console.log(date.getDay()); Задача 1⋕js.Pm.Tm.WG.1 Выведите на экран номер текущего дня недели.

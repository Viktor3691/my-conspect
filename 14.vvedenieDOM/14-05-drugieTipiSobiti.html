Другие типы событий в JavaScript

Кроме клика по элементу, существуют и другие события. Например, с помощью события dblclick можно отловить двойной клик по элементу, с помощью события mouseover - наведение курсора на элемент, а с помощью события mouseout - уход курсора с элемента. Задача 1⋕js.Pm.Dm.ET.1 Дана кнопка. По двойному клику по ней выведите на экран какое-нибудь сообщение. Задача 2⋕js.Pm.Dm.ET.2 Дана кнопка. По наведению на нее выведите на экран какое-нибудь сообщение. Задача 3⋕js.Pm.Dm.ET.3 Дана кнопка. По уходу курсора с нее выведите на экран какое-нибудь сообщение. Ловим несколько событий на элементе К одному элементу можно привязывать обработчики различных типов событий. Давайте, например, привяжем к одному элементу реакцию на наведение курсора и реакцию на уход: button.addEventListener('mouseover', function() { alert('1'); // выведет по наведению }); button.addEventListener('mouseout', function() { alert('2'); // выведет по уходу курсора });

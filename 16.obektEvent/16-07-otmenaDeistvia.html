Отмена действия по умолчанию в JavaScript

Иногда с помощью JavaScript требуется отменить действие тега по умолчанию. К примеру, по нажатию на ссылку отменить переход по этой ссылке. Как правило такое требуется в том случае, если эту ссылку мы используем просто для запуска какого-либо кода. В этом случае то, что при клике на ссылку произойдет переход по ней, нам совсем не нужно. Отмена действия по умолчанию производится с помощью объекта Event. Для этого у него есть специальный метод preventDefault(), который следует вызвать в любом месте обработчика события.

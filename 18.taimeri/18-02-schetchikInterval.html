Счетчик через функцию setInterval в JavaScript

Конечно же, не очень интересно то, что наш таймер каждый раз выводит одно и тоже. Давайте усложним нашу задачу и сделаем так, чтобы каждую секунду в консоль выводились числа по возрастанию: сначала 1, потом 2, потом 3 и так далее. Для этого нам понадобится переменная-счетчик, которая будет хранить свои значения между запусками функции. Несложно понять, что можно просто сделать глобальную переменную: let i = 0; // глобальная переменная setInterval(function() { i++; console.log(i); }, 1000); Перепишем более компактно: let i = 0; setInterval(function() { console.log(++i); }, 1000); Или еще более компактно через стрелочную функцию: let i = 0; setInterval(() => console.log(++i), 1000); Задача 1⋕js.Pm.Tmr.Cn.1 Пусть дана переменная, в которой изначально хранится число 100. Запустите таймер, который каждую секунду будет уменьшать значение этой переменной на 1 и выводить это значение в консоль.

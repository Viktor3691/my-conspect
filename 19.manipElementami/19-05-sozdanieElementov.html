Создание элементов из массива на JavaScript

Пусть у нас есть некоторый массив: let arr = [1, 2, 3, 4, 5]; Пусть также у нас есть некоторый элемент-родитель:
Давайте добавим в наш родитель новые абзацы, текстом которых будут элементы нашего массива. Реализуем описанное: let parent = document.querySelector('#parent'); let arr = [1, 2, 3, 4, 5]; for (let elem of arr) { let p = document.createElement('p'); p.innerHTML = elem; parent.appendChild(p); } Задача 1⋕js.Pm.Mn.ECVA.1 Модифицируйте мой код так, чтобы по клику на абзац к его содержимому прибавлялась единица.

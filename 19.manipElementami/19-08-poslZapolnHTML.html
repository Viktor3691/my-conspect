Последовательное заполнение HTML таблиц

Пусть у нас есть вот такая пустая HTML таблица:
Давайте заполним эту таблицу ячейками и сделаем так, чтобы в этих ячейках шли числа от 1 до 9. Вот пример того, что у нас должно получится:
1 2 3
4 5 6
7 8 9
Давайте приступим к реализации. Для начала давайте просто сделаем таблицу размером 3 на 3, заполненную буквами 'x': let table = document.querySelector('#table'); for (let i = 0; i < 3; i++) { let tr=document.createElement('tr'); for (let i=0; i < 3; i++) { let td=document.createElement('td'); td.innerHTML='x' ; tr.appendChild(td); } table.appendChild(tr); } Давайте теперь сделаем так, чтобы вместо букв 'x' в ячейки записывались числа по возрастанию. Для этого нам необходимо ввести еще один счетчик, который будет последовательно увеличивать свои значения в каждой итерации внутреннего цикла, вот так: let table=document.querySelector('#table'); let k=1; // начальное значение счетчика for (let i=0; i < 3; i++) { let tr=document.createElement('tr'); for (let i=0; i < 3; i++) { let td=document.createElement('td'); td.innerHTML=k; // записываем счетчик в ячейку k++; // увеличиваем счетчик tr.appendChild(td); } table.appendChild(tr); } Задача 1⋕js.Pm.Mn.TCF.1 Выведите на экран таблицу table размером 5 рядов на 5 колонок так, чтобы в ее ячейках последовательно стояли числа от 1 до 25. Задача 2⋕js.Pm.Mn.TCF.2 Модифицируйте предыдущую задачу так, чтобы в ячейках таблицы были записаны четные числа в промежутке от 2 до 50.

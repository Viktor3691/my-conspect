Порядковый номер ячейки таблицы на JavaScript

Давайте теперь запишем в текст каждой ячейки ее порядковый номер. В этом случае нам уже понадобится обычный цикл for со счетчиком, а не for-of: let tds = document.querySelectorAll('#table td'); for (let i = 0; i < tds.length; i++) { tds[i].innerHTML=i + 1; } Можно написать решение и с циклом for-of, просто сделав переменную-счетчик: let tds=document.querySelectorAll('#table td'); let i=1; for (let td of tds) { td.innerHTML=i; i++; } Можно переписать код короче: let tds=document.querySelectorAll('#table td'); let i=1; for (let td of tds) { td.innerHTML=i++; } Задача 1⋕js.Pm.Mn.TCON.1 Дана HTML таблица. Запишите в каждую ячейку ее порядковый номер с конца. То есть последней ячейке запишите 1, предпоследней - 2, и так далее.

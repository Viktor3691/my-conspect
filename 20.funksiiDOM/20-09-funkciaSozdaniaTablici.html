Функция для создания таблицы из двухмерного массива

В предыдущих уроках мы с вами сделали функцию createTable, которая создает таблицу заданного размера. Давайте теперь сделаем функцию createTableByArr, которая параметром будет принимать двухмерный массив и строить на его основе таблицу. То есть приведенный код предыдущего урока преобразуется вот в такой: let div = document.querySelector('#elem'); let arr = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]; let table = createTableByArr(arr); div.appendChild(table); В результате выполнения этого кода должна получится следующая таблица:
1 2 3
4 5 6
7 8 9

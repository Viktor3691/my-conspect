Личный учебный конспект по JavaScript. Содержит теорию, примеры кода и задачи по всем основным темам.

- **01. Основы** — запуск, переменные, типы данных, операторы.
- **02. Коллекции** — массивы, объекты, методы.
- **03. Условия** — if-else, switch-case, тернарный оператор.
- **04. Циклы** — for, while, for-of, for-in.
- **05. Многомерность** — многомерные массивы и объекты.
- **06. Стандартные методы** — Math, строки, массивы.
- **07. Пользовательские функции** — параметры, return.
- **08. Практика на функции** — задачи.

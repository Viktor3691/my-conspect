Переменные

Переменная — это «коробка» с именем, в которой хранится значение. В современном JavaScript используют let и const.

let — изменяемая переменная

Значение можно перезаписывать сколько угодно раз:

let x = 5; x = 10; // перезаписали x = x + 1; // теперь 11 console.log(x); // 11

const — константа

Значение const нельзя перезаписать после объявления — попытка вызовет ошибку:

const PI = 3.14; PI = 3.15; // ❌ Ошибка: Assignment to constant variable

Объявление без значения

let a; // undefined a = 5; // теперь 5 console.log(a);

Имена переменных

Правила именования:

  • Можно буквы, цифры, $ и _
  • Нельзя начинать с цифры
  • Регистр важен: age ≠ Age
  • Нельзя использовать зарезервированные слова (let, const, if)

Типы данных

Тип Пример
Число (number) let n = 42;
Строка (string) let s = 'Привет';
Булево (boolean) let b = true;
Массив (array) let arr = [1, 2, 3];
Объект (object) let obj = { name: 'Иван' };
undefined let u;
null let n = null;

Проверить тип можно оператором typeof: typeof 42 вернёт 'number'.
